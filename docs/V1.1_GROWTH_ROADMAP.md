## 📊 1. Empirical Feedback & Evidence Review

Following the 25-user Beta cohort testing (detailed in `docs/BETA_REPORT.md`) and initial production launch telemetry-free support inquiries, user signals were categorized into three distinct operational themes:

### A. Real-World Storage Patterns
1. **Emerging JavaScript & TypeScript Runtimes:**
   - Developers actively using **Bun** (`~/.bun/install/cache`) and **Deno** (`~/Library/Caches/deno`) accumulated between 4 GB and 14 GB of untracked package caches that escaped generic cleaners.
2. **Game Engines & Creative Toolchains:**
   - Mobile and game developers running **Unity** and **Unreal Engine** reported massive cache directories (`Library/Unity/cache`, DerivedDataCache) exceeding 40 GB on active projects.
3. **Swift Package Manager (SPM) Artifacts:**
   - Swift and iOS developers noted that SPM caches in `~/Library/Caches/org.swift.swiftpm` frequently grow to 10+ GB independently of Xcode DerivedData.

### B. Usability & Workflow Integrations
1. **Terminal-Centric Workflow Demand:**
   - 68% of surveyed developer beta testers indicated they spend the majority of their day inside Ghostty, iTerm2, or VS Code terminal, requesting a lightweight CLI companion (`warren`) to trigger scans or dry-run cleanups without opening the GUI.
2. **Raycast / Spotlight Integration:**
   - Power users on macOS Sonoma and Sequoia heavily requested a Raycast extension to inspect free disk space, trigger a quick scan, or purge Xcode DerivedData directly via shortcut.
3. **APFS Snapshot Transparency:**
   - Users frequently confuse APFS local snapshots (`tmutil listlocalsnapshots`) with unexplained storage usage. Clear detection of purgeable APFS snapshot space was highlighted as a high-value trust builder.

### C. Funnel & Conversion Insights
- **Top Converting Organic Entry Points:** `/how-to-delete-ollama-models` and `/mac-cleaner-for-developers`.
- **Conversion Driver:** Trust in the Trash-first safety model and one-time perpetual pricing ($29) compared to predatory CleanMyMac X annual subscriptions.

## 🛠️ 3. v1.1 Feature Specifications

### 3.1 Extended Rule Registry
Add high-confidence rules with conservative risk tiers to `CleanupRuleRegistry.swift`:
```swift
// Bun Cache Rule
CleanupRule(
    id: "bun-cache",
    name: "Bun Package Cache",
    category: .node,
    defaultPathPattern: "~/.bun/install/cache",
    riskTier: .low,
    description: "Cached package tarballs downloaded by Bun package manager.",
    safetyRecommendation: "Safe to remove. Bun will re-download packages on next install."
)

// Swift Package Manager Cache Rule
CleanupRule(
    id: "swiftpm-cache",
    name: "Swift Package Manager Cache",
    category: .xcode,
    defaultPathPattern: "~/Library/Caches/org.swift.swiftpm",
    riskTier: .low,
    description: "Downloaded Git repositories and cloned dependency artifacts from SPM.",
    safetyRecommendation: "Safe to remove. Xcode/Swift CLI will fetch dependencies when building."
)
```

### 3.2 Native CLI Companion (`warren`)
A standalone, zero-dependency Universal command-line utility sharing `DiskWarrenCore`:
- `warren scan [--path <dir>] [--json]` — Fast filesystem scan with summary breakdown.
- `warren doctor` — Evaluates disk health, Full Disk Access status, and purgeable developer space.
- `warren clean --category <name> --dry-run` — Safe dry-run candidate preview.
- `warren clean --category <name> --confirm` — Recycles matched items to Trash.

### 3.3 Official Raycast Extension
- Direct TypeScript Raycast extension utilizing `warren` CLI / local IPC.
- Commands:
  - *Scan Disk Space* (shows circular gauge and top 5 disk hogs).
  - *Purge Xcode DerivedData* (one-key safe developer clean).
  - *Clean Stale node_modules* (presents candidate projects for interactive review).

## 📅 4. Release Cadence & Governance

1. **Bi-Weekly Minor Releases (v1.0.x):**
   - Scheduled every second Tuesday.
   - Incorporates new detection rules, macOS point release compatibility patches, and localization updates.
2. **Quarterly Feature Milestones (v1.x.0):**

   - SLA: Shipped, signed, and notarized within 24 hours of report.
   - Pushed via Sparkle 2 urgent update channel.

## 🛡️ 5. Non-Negotiable Safety Invariants for Future Releases

1. **Trash-First Must Never Be Weakened:** No future flag or setting may introduce an unrecoverable `rm -rf` option.
2. **Zero Telemetry Commitment Is Permanent:** No telemetry SDK may be introduced, regardless of future enterprise or team features.
3. **No Automatic Background Deletions:** DiskWarren remains an intentional, explicit, user-directed intelligence tool.
